# 医语公开试学样例

这是独立编写的三个医学术语试学页，提供术语辨义、无选项提取和患者用语判断三种路线。界面由 React Native 实现，导出为网页。样例不能代表考试成绩或临床能力。

运行 `npm install` 后执行 `npm run build`，生成的 `dist` 可作为 GitHub Pages 的网站根目录。构建末尾会检查样例术语和已知完整课程、云同步标识，发现异常时返回失败。此检查只能发现已列出的标识，不能证明内容权利，也不能阻止绕过构建流程直接上传其他文件。完整课程不在此样例中；根项目的 `build:web:trial` 生成的是完整应用网页包，不可误当作本样例发布。
